**Название проекта**: Jewelry Workshop API

**Описание**:  
Это полноценный RESTful backend для управления ювелирной мастерской. Проект реализован с нуля на Java и Spring Boot 3. Он охватывает все ключевые аспекты enterprise-разработки: безопасность, архитектуру, документацию, DevOps и аналитику. Разработан в одиночку как демонстрация профессиональных навыков backend-разработчика.

**Основные возможности**:

1. **Аутентификация и авторизация**  
   - Регистрация с email-верификацией  
   - Вход по email/паролю с выдачей JWT (access + refresh токены)  
   - Сброс пароля через email  
   - Поддержка трёх ролей: CLIENT, SELLER, ADMIN  
   - RBAC (Role-Based Access Control) через аннотации @PreAuthorize  
   - Rate limiting на критические эндпоинты (например, /login)  
   - Защита от CSRF, валидация входных данных, глобальная обработка ошибок

2. **Управление клиентами**  
   - Просмотр и редактирование профиля (/clients/me)  
   - Смена пароля с проверкой текущего  
   - Поиск клиентов по ФИО, телефону, статусу постоянного клиента, количеству заказов  
   - Назначение постоянного клиента (для расчёта LTV и скидок)

3. **Изделия и материалы**  
   - Полный CRUD для изделий и материалов (только для ADMIN)  
   - Гибкий поиск изделий с пагинацией, фильтрацией и сортировкой  
   - Учёт остатков на складе — при создании заказа остатки уменьшаются, при отмене — возвращаются  
   - Связь «многие-ко-многим» между изделиями и материалами

4. **Заказы**  
   - Создание заказа с автоматическим расчётом итоговой суммы и скидки  
   - Отмена заказа с возвратом товаров на склад  
   - Изменение статуса: PENDING → PROCESSING → COMPLETED или CANCELLED  
   - История заказов для клиента  
   - Просмотр всех заказов (для ADMIN и SELLER)

5. **Аналитика и отчёты**  
   - Ежедневная статистика: выручка, средний чек, количество заказов  
   - Отчёт по клиентам: LTV (Lifetime Value), топ-покупатели, новые клиенты за период  
   - Отчёт по изделиям: популярность, общая выручка, остатки на складе  
   - Системные метрики: общее число пользователей, заказов, активных изделий

6. **Администрирование**  
   - Просмотр системных логов аудита (таблица audit_log)  
   - Создание, редактирование и деактивация пользователей  
   - Автоматическое создание первого администратора при первом запуске (профиль init-admin)

**Технологический стек**:

- Язык: Java 
- Фреймворк: Spring Boot 3, Spring Security, Spring Data JPA, Spring Validation  
- Безопасность: JWT, BCrypt, Redis (для хранения refresh-токенов), RBAC, rate limiting  
- База данных: PostgreSQL 15  
- Миграции: Flyway  
- Кэширование и сессии: Redis  
- Документация: OpenAPI 3 / Swagger UI  
- DevOps: Docker (multi-container: приложение + PostgreSQL + Redis), Gradle  
- Архитектура: Clean Architecture с разделением на presentation, service, domain и infrastructure слои

**Архитектура проекта**:

Проект строго следует принципам Clean Architecture:
- presentation — контроллеры, DTO, обработка исключений
- service — бизнес-логика, мапперы
- domain — сущности, репозитории, интерфейсы сервисов
- infrastructure — внешние зависимости: email, Redis, настройки

Все зависимости инжектятся через конструктор. Используются кастомные мапперы вместо MapStruct. Все ответы стандартизированы через глобальный обработчик ошибок.

**Запуск с Docker**:

1. Установите Docker и Docker Compose  
2. Склонируйте репозиторий  
3. Выполните: `docker-compose up --build`  
4. API будет доступен на http://localhost:8080

При первом запуске с профилем `init-admin` создаётся администратор:  
Email: admin@jewelry.local  
Пароль: SecureAdminPass123!  
(Обязательно смените пароль после первого входа!)

**Документация API**:

После запуска:
- Swagger UI: http://localhost:8080/swagger-ui.html  
- OpenAPI Spec: http://localhost:8080/v3/api-docs

Все эндпоинты защищены JWT. Для тестирования нужно зарегистрироваться, подтвердить email, авторизоваться и использовать полученный токен в заголовке Authorization.
